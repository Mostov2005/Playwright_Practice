# Автоматизированное тестирование сайта Полдела24

## 1. Общая информация

Для автоматизации тестирования интернет-магазина Полдела24 разработан набор UI- и E2E-тестов на Python с использованием Playwright и Pytest.

Реализованы проверки авторизации, поиска товаров, отображения информации о товаре, добавления товара в корзину и заполнения формы оформления заказа.

**Текущий состав набора — 13 автоматизированных тестов.** При последнем полном запуске все 13 тестов успешно пройдены.

### 2.6. Сквозной E2E-сценарий

**E2E-01. Прохождение пользовательского сценария покупки товара.**

Последовательность действий:

1. Авторизация пользователя.
2. Поиск товара.
3. Открытие карточки товара.
4. Добавление товара в корзину.
5. Переход в корзину и проверка товара.
6. Переход к оформлению заказа.
7. Заполнение необходимых данных.
8. Проверка заполненных данных и выбранных параметров доставки.

**Ожидаемый результат:** пользователь успешно проходит путь от авторизации до заполнения формы оформления заказа.

Статус: ✅

Финальная кнопка подтверждения заказа не нажимается, чтобы не создавать реальные заказы на сайте.

## 4. Технологический стек и организация проекта

- Язык программирования: Python 3.11.
- Автоматизация браузера: Playwright.
- Тестовый фреймворк: Pytest.
- Формирование отчётов: Allure.
- Архитектура: Page Object Model (POM).
- Логирование: INFO и ERROR.
- Учётные данные хранятся в `.env`.
- Для изоляции тестов используется отдельная страница браузера для каждого теста.
- Настроено логирование начала и результата выполнения тестов.
- При ошибке теста автоматически создаётся скриншот страницы.
- Логи и скриншоты прикрепляются к соответствующему тесту в отчёте Allure.

## 5. Запуск тестов и просмотр отчёта

### 5.1. Запуск автоматизированных тестов

Команда запуска полного набора:

```powershell
pytest autotest/ -v -s
```

После выполнения Pytest результаты тестирования сохраняются в каталоге `reports/allure-results`.

### 5.2. Открытие отчёта Allure

Для формирования и открытия интерактивного отчёта используется команда:

```powershell
allure serve reports/allure-results
```

Команда запускает локальный сервер и автоматически открывает отчёт в браузере.

В отчёте можно посмотреть:

- общую статистику выполнения тестов;
- успешные и неуспешные проверки;
- последовательность шагов каждого теста;
- логи выполнения;
- скриншоты страниц при ошибках.
