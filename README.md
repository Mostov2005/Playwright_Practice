# Автоматизированное тестирование сайта ПолДела24

Проект автоматизированного UI- и E2E-тестирования интернет-магазина [ПолДела24](https://полдела24.рф/).

Тестирование реализовано на Python с использованием Playwright, Pytest и Allure.

## Возможности проекта

- Автоматизированная проверка авторизации.
- Проверка поиска товаров.
- Проверка информации в карточке товара.
- Проверка добавления товара в корзину.
- Проверка заполнения формы оформления заказа.
- Сквозной E2E-сценарий покупки товара.
- Логирование выполнения тестов.
- Автоматическое создание скриншотов при ошибках.
- Формирование интерактивных отчётов Allure.

### Архитектура

В проекте используется паттерн Page Object Model (POM).

- **core** — конфигурация проекта и настройка логирования.
- **ui** — базовый класс страницы и Page Object для отдельных страниц сайта.
- **autotest** — автоматизированные тесты.
- **conftest.py** — общие фикстуры Pytest, настройка браузера, логирование и интеграция с Allure.

## Реализованные тесты

В основном наборе реализовано 13 автоматизированных тестов.

### Авторизация — 6 тестов

- Успешная авторизация.
- Авторизация с неправильным паролем.
- Авторизация с неизвестным E-Mail.
- Отправка формы с пустым E-Mail.
- Отправка формы с пустым паролем.
- Проверка некорректного формата E-Mail.

### Поиск товаров — 2 теста

- Поиск существующего товара.
- Поиск несуществующего товара.

### Карточка товара — 1 тест

- Проверка названия, стоимости за квадратный метр, стоимости упаковки и информации об упаковке.

### Корзина — 1 тест

- Добавление товара в корзину и проверка его отображения.

### Оформление заказа — 1 тест

- Заполнение формы оформления заказа и проверка данных покупателя и параметров доставки.

### E2E — 1 тест

Сквозной пользовательский сценарий:

1. Авторизация.
2. Поиск товара.
3. Открытие карточки товара.
4. Добавление товара в корзину.
5. Проверка содержимого корзины.
6. Переход к оформлению заказа.
7. Заполнение формы.
8. Проверка данных и параметров доставки.

Финальное подтверждение заказа не выполняется, чтобы не создавать реальные заказы.

### Техническая проверка — 1 тест

- Проверка возможности запуска и использования браузера Chromium.

Дополнительно предусмотрен демонстрационный тест `test_failure_demo.py`, который намеренно завершается ошибкой для проверки создания скриншотов и прикрепления логов в Allure. Он не относится к основным функциональным тестам.

## Логирование и отчётность

Для логирования используется стандартный модуль Python `logging`.

Настроены уровни:
- DEBUG — подробная информация в файле логов.
- INFO — основные события выполнения тестов.
- ERROR — информация об ошибках.

Логи сохраняются в `logs/test.log`.

Для каждого теста в отчёте Allure прикрепляются логи выполнения. Если тест завершается ошибкой, дополнительно создаётся скриншот страницы.

Allure позволяет просматривать:
- результаты выполнения тестов;
- шаги тестирования;
- логи;
- скриншоты при ошибках;
- общую статистику.

## Установка и настройка проекта

### 1. Клонирование репозитория

```powershell
git clone <URL-репозитория>
cd Playwright_Practice
```

### 2. Создание виртуального окружения

```powershell
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```powershell
pip install -r requirements.txt
```

### 4. Установка браузера Chromium

```powershell
playwright install chromium
```

### 5. Настройка переменных окружения

Создать файл `.env` на основе `.env.example` и заполнить необходимые параметры.

Файл `.env` содержит локальные настройки и учётные данные. Он не должен добавляться в Git.

## Запуск тестов

Запуск всего основного набора:

```powershell
pytest autotest/ -v -s
```

Запуск отдельного файла:

```powershell
pytest autotest/test_auth.py -v -s
```

Запуск отдельного теста:

```powershell
pytest autotest/test_auth.py::test_successful_login -v -s
```

## Allure

Результаты выполнения тестов автоматически сохраняются в:

```text
reports/allure-results/
```

Для просмотра интерактивного отчёта необходимо выполнить:

```powershell
allure serve reports/allure-results
```

Команда сформирует отчёт и откроет его в браузере.

Для работы Allure Commandline требуется установленная Java и Allure CLI.
